# 版本演进 v1 → v22c → 仓库版

每次迭代都在这台设备上推上去实机点测，`_backup/` 里留了同名快照。列"取舍"是为了说明"为什么最后长这样"，而不是记流水账。

| 版本 | 主题 | 做了什么 | 取舍 / 学到的 |
| --- | --- | --- | --- |
| v1 | 单页时钟 | 黑底、大数字、单页 | 基线，也是唯一留作退路的极简版（5.3KB） |
| v2 | 双页 iPad 浅色 | 浅色卡片风、左右滑 | 浅色在这个背光屏上发灰，很快被深色取代；**未留档** |

| repo-1 | 仓库化（2026-11-09） | 七首 iOS 铃声换成自制的 988+1319Hz 合成提示音；番茄钟补 `beepLoop()` 兜底；体积 5.5MB → 240KB | 对外分发的版本不能带第三方音频，但也不该把铃声功能整个砍掉——留一段自制音频，逻辑完整、可点、有声 |
| v22c | 刷新不丢倒计时（2026-11-09） | `cdState_v1` 落盘绝对结束时刻；`cdStart()` / 到点翻转 / `cdStop()` 三处写，初始化时 `cdRestoreState()` 接回；到点被重载吞掉时（≤60s）补"时间到"并响铃。真机已验三条分支（接着跑 / 到点落在重载窗口内 / 超过 60s 清记录），取证见 PITFALLS D5 | 番茄钟早就是这个范式（`pomo_s1` 存 `end`）；存"剩余秒数"会被 14~35s 的首渲白吃，所以必须存时间戳 |
| repo-2 | 同一补丁进仓库（2026-11-09） | `page/index.html` 同步为 242,206 B / `c67bbded…`；`PITFALLS` 增 D5 | 两版只差 `RINGS` 与 `pmChime` 兜底，补丁必须两边同改，否则文档公示的 md5/体积当场失效 |

仓库版（`repo-2`）与真机版（`v22c`）的差异只有三处：`RINGS` 里 7 段 `data:audio/mpeg` → 1 段 `data:audio/wav`；`pmChime()` 多了 1.5s 失败回落的 `beepLoop()` 与 6s 收尾清 `beepTimer`；文件体积。其余代码、坐标、配色完全一致，所以上面的尺寸表与坐标表对两版都成立。倒计时持久化（`cdState_v1` / `cdRestoreState()`）两版逐字相同。

## 没做 / 待定（诚实清单）

- **真翻页动画**：目前只有静态翻页板质感（遮罩 + 缝 + 投影），上片 `rotateX` 翻下去的动画一直没实现。若要加，建议只在分钟变化时翻，避免秒位每帧抖。
- **夜间自动调暗 / 整点报时**：提出过，未做。
- **日历视图形态**：目前单一月视图；周视图 / 议程视图没定。
- **铃声共用通道**：倒计时与番茄各自有独立停止定时器（`alarmStop` vs `pmRingTimer`），没有合并。
- **`cdRing_v1` 存索引的脆弱性**：调整 `RINGS` 顺序会让旧值指错铃声，未处理（可改成存名字）。
- **语音四件套是否真的能唤醒出声**：一直保留、从未验证。
- **`com.ktcp.aiagent` 是什么**：未知，未动。
- **`倒计时 00:00:03` 残留**：偶发于"到点后没人按停止、直接 force-stop 重载"，根因未定位。
